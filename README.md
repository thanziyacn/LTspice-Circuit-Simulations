
# LTspice Circuit Simulations ⚡

A collection of practical LTspice circuit simulations with theoretical calculations, waveforms, results, and documentation.

## 🎯 Objective

To learn circuit simulation using LTspice and understand the relationship between theoretical circuit analysis and simulated results.

## 📚 Topics Covered

- Basic Circuit Analysis
- DC Analysis
- Transient Analysis
- AC Analysis
- Diode Circuits
- Rectifiers
- BJT Circuits
- MOSFET Circuits
- Op-Amp Circuits
- Filters
- Power Electronics

## 🛠️ Software Used

- LTspice
- Git & GitHub

## 📈 Learning Approach

Each circuit is studied using:

1. Theoretical analysis
2. Circuit implementation in LTspice
3. Simulation
4. Waveform analysis
5. Comparison of theoretical and simulated results
6. Documentation
